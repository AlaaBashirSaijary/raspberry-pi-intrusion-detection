# 04_cooper_cnn_tflite

## البحث
- المؤلف الأول: Cooper
- المرجع الكامل (العنوان، السنة، DOI): **[يُستكمل من الورقة]**
- النموذج: CNN مضغوط (TFLite)

## ماذا طبّقتُ من البحث
- شبكة Conv1D(16, kernel=3) ← GlobalMaxPooling ← Dense(16) ← Dense(1, sigmoid)، تُدرَّب 5 epochs بحجم دفعة 256 ومُحسِّن Adam.
- بعد التدريب يُحوَّل النموذج إلى `models/cooper_cnn.tflite` مع `Optimize.DEFAULT` (تكميم ديناميكي).
- القياس على Pi يتم على ملف `.tflite` عبر `tflite_runtime`.

الكود: `train.py` في هذا المجلد، ويمرّر دالة بناء النموذج فقط إلى `common/runner.py`. التقسيم والتطبيع والمقاييس مشتركة مع بقية الأبحاث.

## ما الذي اختلف عن الورقة الأصلية ولماذا
- **البنية:** صغيرة ثابتة اخترتُها لتناسب الجهاز، وقد تختلف عن بنية الورقة **[تُستكمل]**.
- **التعامل مع الخصائص كتسلسل:** الخصائص الجدولية تُعامل كقناة واحدة بطول عدد الخصائص، وهذا افتراض قد لا يطابق الورقة.
- **حالة الاختبار:** لم يُشغَّل هذا النموذج بعد في بيئة التطوير لغياب TensorFlow، فمسار التحويل والقياس بحاجة لتجربة أولى.
- **المعاملات الفائقة:** ثابتة كما في `train.py` وغير مضبوطة بالبحث عن الأفضل. القيم الأصلية في الورقة: **[تُستكمل من الورقة، وتُسجَّل هنا أي فروق]**.
- **التصنيف:** ثنائي (طبيعي/هجوم) في كل الأبحاث لتوحيد المقارنة، حتى لو اعتمدت الورقة تصنيفاً متعدد الفئات.
- **البيانات والجهاز:** مجموعتا Edge-IIoTset وNetFlow على تقسيم 70/30 مع 5 بذور، والقياس على Raspberry Pi واحد. لذلك لا تُقارن الأرقام بأرقام الورقة مباشرة.

## التشغيل
```bash
pip install tensorflow          # على اللابتوب فقط
python papers/04_cooper_cnn_tflite/train.py --data data/edge_iiotset.csv --label-col Attack_label
# على Pi: pip install tflite-runtime
python common/measure_pi.py --model models/cooper_cnn.tflite --watts <قراءة المقياس>
```

ملاحظة: النتائج المسجَّلة على اللابتوب هي لنموذج Keras، بينما قياسات Pi لنموذج TFLite المكمَّم. قد تختلف دقتهما قليلاً.

## النتيجة في هذا المشروع
بانتظار البيانات الحقيقية وجهاز Raspberry Pi. بعد التشغيل تُنقل هنا الأسطر الخاصة بهذا النموذج من `results/comparison.md`: Accuracy وF1 وTPR وFPR (متوسط ± انحراف على 5 بذور)، داخل المجموعة وعبر المجموعتين، وزمن الاستدلال والذاكرة وحجم النموذج على Pi.
