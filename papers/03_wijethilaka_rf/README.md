# 03_wijethilaka_rf

## البحث
- المؤلف الأول: Wijethilaka
- المرجع الكامل (العنوان، السنة، DOI): **[يُستكمل من الورقة]**
- النموذج: Random Forest

## ماذا طبّقتُ من البحث
- `RandomForestClassifier` بـ 100 شجرة.
- `n_jobs=-1` أثناء التدريب فقط. أثناء قياس Pi يُضبط `n_jobs=1` لأن الاستدلال يتم على صف واحد.

الكود: `train.py` في هذا المجلد، ويمرّر دالة بناء النموذج فقط إلى `common/runner.py`. التقسيم والتطبيع والمقاييس مشتركة مع بقية الأبحاث.

## ما الذي اختلف عن الورقة الأصلية ولماذا
- **عدد الأشجار والعمق:** افتراضيان هنا **[تُقارَن بالورقة]**.
- **حجم النموذج:** الغابة الكبيرة تنتج ملفاً بحجم عدة ميغابايت (≈7 MB في تجربة الخط الوهمية)، وهو رقم يهم الأجهزة المحدودة ويُقاس فعلياً على Pi.
- **المعاملات الفائقة:** ثابتة كما في `train.py` وغير مضبوطة بالبحث عن الأفضل. القيم الأصلية في الورقة: **[تُستكمل من الورقة، وتُسجَّل هنا أي فروق]**.
- **التصنيف:** ثنائي (طبيعي/هجوم) في كل الأبحاث لتوحيد المقارنة، حتى لو اعتمدت الورقة تصنيفاً متعدد الفئات.
- **البيانات والجهاز:** مجموعتا Edge-IIoTset وNetFlow على تقسيم 70/30 مع 5 بذور، والقياس على Raspberry Pi واحد. لذلك لا تُقارن الأرقام بأرقام الورقة مباشرة.

## التشغيل
```bash
python papers/03_wijethilaka_rf/train.py --data data/edge_iiotset.csv --label-col Attack_label
python papers/03_wijethilaka_rf/train.py --data data/edge_iiotset.csv --test-data data/netflow.csv --label-col Label
python common/measure_pi.py --model models/wijethilaka_rf.joblib --watts <قراءة المقياس>
```
