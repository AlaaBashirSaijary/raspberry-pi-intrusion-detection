# 01_sai_svm

## البحث
- المؤلف الأول: Sai
- المرجع الكامل (العنوان، السنة، DOI): **[يُستكمل من الورقة]**
- النموذج: SVM مع اختيار خصائص

## ماذا طبّقتُ من البحث
- آلة متجهات الدعم بنواة RBF (`SVC`, C=1.0).
- اختيار الخصائص بـ `SelectKBest(f_classif, k=20)`، ويقع داخل الـ pipeline فيُحسب على بيانات التدريب فقط، فلا تسرّب من الاختبار.

الكود: `train.py` في هذا المجلد، ويمرّر دالة بناء النموذج فقط إلى `common/runner.py`. التقسيم والتطبيع والمقاييس مشتركة مع بقية الأبحاث.

## ما الذي اختلف عن الورقة الأصلية ولماذا
- **عدد الخصائص k=20 وقيمة C:** اختيارات ثابتة هنا، لا تُحسب من الورقة.
- **حجم البيانات:** تدريب SVM تعقيده يقارب O(n²)، فلا يصلح لملايين الصفوف. يُستخدم `--max-rows` لأخذ عيّنة طبقية ثابتة، ويجب ذكر حجمها مع النتائج.
- طريقة اختيار الخصائص في الورقة **[تُستكمل]**، وقد تختلف عن اختبار F الأحادي المستخدم هنا.
- **المعاملات الفائقة:** ثابتة كما في `train.py` وغير مضبوطة بالبحث عن الأفضل. القيم الأصلية في الورقة: **[تُستكمل من الورقة، وتُسجَّل هنا أي فروق]**.
- **التصنيف:** ثنائي (طبيعي/هجوم) في كل الأبحاث لتوحيد المقارنة، حتى لو اعتمدت الورقة تصنيفاً متعدد الفئات.
- **البيانات والجهاز:** مجموعتا Edge-IIoTset وNetFlow على تقسيم 70/30 مع 5 بذور، والقياس على Raspberry Pi واحد. لذلك لا تُقارن الأرقام بأرقام الورقة مباشرة.

## التشغيل
```bash
python papers/01_sai_svm/train.py --data data/edge_iiotset.csv --label-col Attack_label --max-rows 100000
python common/measure_pi.py --model models/sai_svm.joblib --watts <قراءة المقياس>
```
